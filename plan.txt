
The strategy:

# Final Tech Stack (₹0 MVP)

## Core Stack

| Purpose         | Tool                | Why                        |
| --------------- | ------------------- | -------------------------- |
| Framework       | Next.js             | Website + dashboard + APIs |
| Language        | TypeScript          | Fewer bugs                 |
| Styling         | Tailwind CSS        | Fast UI                    |
| Components      | shadcn/ui           | Professional UI fast       |
| Hosting         | Vercel              | Free deployment            |
| Database        | Supabase PostgreSQL | Relational + RLS security  |
| Authentication  | Supabase Auth       | Built-in users             |
| Images          | Cloudflare R2       | Cheap/free image storage   |
| ORM             | Prisma              | Database management        |
| Forms           | React Hook Form     | Form handling              |
| Validation      | Zod                 | Safe inputs                |
| Charts          | Recharts            | Progress graphs            |
| Emails          | Resend              | Invites/reminders          |
| Analytics       | PostHog             | Track usage                |
| AI              | Google AI Studio    | AI reports                 |
| Background jobs | GitHub Actions      | Scheduled tasks            |
| Offline cache   | IndexedDB           | Gym offline mode           |
